# QGIS workflow

This directory contains the versioned QGIS component of the dissertation. The
active project is `projects/everything.qgz`, currently maintained with QGIS
4.2.0.

## Versioned contents

- `layers/`: local reference layers downloaded manually from GeoSampa or IBGE;
- `projects/everything.qgz`: active dissertation project;
- `scripts/`: the numbered maintenance, validation, and export pipeline plus
  the portable PowerShell launcher;
- `templates/`: transport and land-use layout templates.

Backups, caches, debugging helpers, migration scripts, classification reports,
and rendered maps remain local and are excluded by the root `.gitignore`.
Classification reports are regenerated by the numbered scripts. Scenario JPEGs
are regenerated under `paper/maps/`.

## Data sources

The files under `layers/` were downloaded manually from GeoSampa or IBGE. They
are stored in the repository because the QGIS project uses them directly and
there is no complete automated downloader for this collection.

Model inputs and results are read from relative paths under `data/`. The
project also uses the OpenStreetMap XYZ service as a remote basemap, so internet
access is required to reproduce exports containing that background.

## Environment

Run the scripts with the Python environment bundled with QGIS. On Windows, the
portable launcher discovers the newest installation under `Program Files`.
Set `QGIS_PYTHON_BAT` only when QGIS is installed elsewhere.

Example:

```powershell
powershell -ExecutionPolicy Bypass -File `
  qgis/scripts/run_qgis_python.ps1 `
  qgis/scripts/03_01_validate_results_symbology.py
```

The QGIS Python runtime must provide `pyarrow`. Do not create `.python_lib` or a
project-local Python environment.

## Execution order

The complete workflow is:

```text
01_01_update_base_symbology.py
01_02_update_transport_symbology.py
01_03_update_land_use_symbology.py
01_04_update_policy_comparison_symbology.py
02_01_apply_scenario_layout_templates.py
03_01_validate_results_symbology.py
03_02_validate_scenario_layouts.py
04_01_export_scenario_maps.py
```

Scripts `01_*` update result-layer symbology in the active project. Script
`02_01` applies the two templates to the scenario layouts. Scripts `03_*`
validate the stored symbology and layouts. Script `04_01` exports the 22
scenario maps only after validating the complete batch.

The expected validation results are:

```text
03_01: validated_layers=33 and checks=0
03_02: validated_layouts=22 and checks=0
04_01: exported_maps=22
```

The project should be reopened in QGIS after any script changes the
`everything.qgz` file, because an already-open session can retain stale state.
